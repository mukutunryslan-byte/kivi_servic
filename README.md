# Ківі Сервіс — сайт

Односторінковий сайт: HTML/CSS/JS без фреймворків і збірки. Публікація — Netlify (див. **ПУБЛІКАЦІЯ.md**), заявки приймає функція `netlify/functions/lead.mjs`. Для локального запуску — Python-сервер `server.py` з тією самою логікою.

## Запуск локально

```bash
python3 server.py
```

Відкрити http://localhost:8000

## Структура

| Файл | Що в ньому |
|---|---|
| `public/index.html` | Уся сторінка й тексти (статичний HTML — добре індексується) |
| `public/config.js` | Телефони, месенджери, соцмережі, політика, реквізити, відгуки, режим прототипу |
| `public/styles.css` | Стилі; палітра — змінні у `:root` |
| `public/main.js` | Меню, підстановка контактів, вибір послуги, перевірка й надсилання форми |
| `server.py` | Віддає `public/`, приймає `POST /api/lead`, перевіряє заявку, ліміт 5 заявок / 10 хв з IP, надсилає заявку в Telegram |
| `netlify/functions/lead.mjs` | Приймання заявок на Netlify: перевірка, пастка для ботів, ліміт частоти, Telegram |
| `netlify.toml` | Налаштування Netlify: папка сайту `public`, без збірки |
| `public/privacy.html` | Політика конфіденційності |
| `public/_headers`, `public/robots.txt` | Заголовки безпеки й кешування, дозвіл індексації |
| `.env.example` | Шаблон налаштувань бота; робочий файл — `.env` (нікому не пересилати) |

## Що реально працює

- Навігація, мобільне меню (Esc закриває), нижня панель «Подзвонити / Залишити заявку» (ховається над формою).
- Кнопки в картках послуг переводять до форми з уже вибраною послугою.
- Перевірка номера в браузері **і на сервері**: `067 123 45 67`, `(067)123-45-67`, `+380671234567`, `80671234567` → `+380671234567`.
- Стани форми: надсилання / помилка / успіх. При помилці введені дані зберігаються.
- Пастка для ботів (приховане поле) і ліміт частоти.
- Блок «Відгуки» прихований, доки в `config.js` немає підтверджених відгуків.

## Що потребує підключення

- **Telegram-бот для заявок** — код готовий, потрібні токен і chat_id (інструкція нижче). Без них форма чесно пише «Заявку не надіслано».
- **Фото** — див. нижче.
- **Шрифт Manrope** — завантажити `Manrope-Variable.woff2` у `public/fonts/` і розкоментувати `@font-face` у `styles.css` (без сторонніх CDN).

## Підключення заявок у Telegram

Сайт не може написати людині в Telegram просто за номером — заявки надсилає бот у чат Романа. Налаштування — один раз, ~2 хвилини, з телефона, де встановлено Telegram на номер 068 018 80 85:

1. Відкрити **@BotFather** → `/newbot` → придумати назву (наприклад, «Ківі Сервіс заявки») та ім’я, що закінчується на `bot`. BotFather надішле **токен** — довгий рядок `123456:ABC…`.
2. Знайти свого нового бота й натиснути **Start** (без цього бот не зможе писати).
3. Дізнатися chat_id: відкрити в браузері `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — у відповіді знайти `"chat":{"id": 123456789` — це число і є **chat_id**.
   Щоб заявки бачили кілька людей: створити групу, додати туди бота, написати в групі будь-що й так само взяти `id` (для групи він від’ємний, наприклад `-100…`).
4. Скопіювати `.env.example` у `.env`, вписати `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`, перезапустити `python3 server.py`.
5. Надіслати тестову заявку з сайту — у Telegram прийде повідомлення з телефоном, населеним пунктом, послугою й коментарем.

Токен — як пароль: не публікувати, не вставляти в `public/` і не пересилати в загальних чатах. Якщо засвітився — `/revoke` у @BotFather.

### Кейси «до / після» — на потім

Зараз блоку на сайті немає. Коли знайдуться 3–6 пар фото **з одного об’єкта**, вставити в `index.html` на місце коментаря «Кейси «до / після» додати сюди» (стилі вже є в `styles.css`):

```html
<h3 class="cases__title">До і після</h3>
<div class="cases">
  <article class="case">
    <div class="case__media">
      <img src="images/case-1-before.jpg" width="900" height="900" loading="lazy" alt="Криниця до чистки: …">
      <img src="images/case-1-after.jpg" width="900" height="900" loading="lazy" alt="Та сама криниця після чистки: …">
    </div>
    <div class="case__body">
      <p class="case__place">Населений пункт</p>
      <h3>Коротка назва кейсу</h3>
      <dl class="case__facts">
        <div><dt>Проблема</dt><dd>…</dd></div>
        <div><dt>Що зроблено</dt><dd>…</dd></div>
        <div><dt>Результат</dt><dd>…</dd></div>
      </dl>
    </div>
  </article>
  <!-- ще 2–5 карток -->
</div>
```

Кандидати з брифу: околиці Львова (~30 років без чистки), Яремче (~40 років), кам’яна криниця (робота Захара). Усі цифри — лише за оригінальними відео. Не використовувати прозорість води на фото як доказ її питної якості.

Для кожного кейсу: локація, проблема, що зроблено, фактичний результат. Не використовувати прозорість води на фото як доказ її питної якості.

## Публікація

Покроково — у файлі **ПУБЛІКАЦІЯ.md**. Уже зроблено: режим прототипу вимкнено, `noindex` прибрано, є політика конфіденційності, `robots.txt`, заголовки безпеки.

Після підключення власного домену: favicon (після логотипа), `og:image`, `sitemap.xml`, schema.org LocalBusiness — лише з підтвердженими даними (без адреси-заглушки, рейтингу, годин роботи).
