# Як опублікувати сайт Ківі Сервіс на Netlify (безкоштовно)

Схема: файли лежать на **GitHub**, а **Netlify** бере їх звідти й показує як сайт. Обидва сервіси безкоштовні. Сайт отримає адресу на кшталт `kivi-service.netlify.app`, власний домен можна підключити пізніше.

Займе ~15 хвилин. Програми встановлювати не треба — усе в браузері.

> Чому не просто перетягнути папку в Netlify Drop? Так завантажуються лише сторінки — функція, що надсилає заявки в Telegram, не запуститься. Через GitHub працює все, а кожна зміна файлів сама оновлює сайт.

---

## Крок 1. Завантажити файли на GitHub

1. Зареєструйтеся на https://github.com/signup (або увійдіть).
2. Угорі праворуч **+** → **New repository**.
   - Repository name: `kivi-service-site`
   - Оберіть **Private** (код бачитимете лише ви — Netlify це не заважає).
   - Натисніть **Create repository**.
3. На сторінці нового репозиторію натисніть посилання **uploading an existing file**.
4. Відкрийте папку з сайтом у Finder і **перетягніть у вікно браузера** ці елементи:
   - папку `public`
   - папку `netlify`
   - `netlify.toml`, `server.py`, `README.md`, `ПУБЛІКАЦІЯ.md`
   - `.gitignore` і `.env.example` — вони приховані; щоб їх побачити, натисніть у Finder **Cmd + Shift + .** (крапка)

   ⚠️ Файл `.env` (якщо створите його для локального запуску) **не завантажувати** — у ньому токен бота.
5. Унизу натисніть **Commit changes**.

## Крок 2. Підключити Netlify

1. Відкрийте https://app.netlify.com/ → **Sign up** → найпростіше обрати **GitHub** (вхід через той самий акаунт).
2. **Add new project** (або **Add new site**) → **Import an existing project** → **GitHub**.
3. Дозвольте Netlify доступ до репозиторію `kivi-service-site` і оберіть його.
4. Налаштування (більшість підтягнеться з `netlify.toml` автоматично):

   | Поле | Значення |
   |---|---|
   | Project name | `kivi-service` (стане адресою `kivi-service.netlify.app`; якщо зайнято — `kivi-service-ua` тощо) |
   | Branch to deploy | `main` |
   | Base directory | *(порожньо)* |
   | Build command | *(порожньо)* |
   | Publish directory | `public` |
   | Functions directory | `netlify/functions` |

5. **Deploy**. За хвилину сайт відкриється за адресою `https://<назва>.netlify.app`.
   Назву можна змінити пізніше: **Project configuration** → **Change project name**.

На цьому етапі сайт уже працює: дзвінки, Telegram, соцмережі, політика. Форма чесно пише «Заявку не надіслано», доки не підключено бота (крок 3).

## Крок 3. Підключити заявки в Telegram (коли буде бот)

1. Створити бота й дізнатися chat_id — див. розділ «Підключення заявок у Telegram» у `README.md`.
2. Netlify → ваш проєкт → **Project configuration** → **Environment variables** → **Add a variable** → **Add a single variable**:
   - `TELEGRAM_BOT_TOKEN` — значення: токен від BotFather; увімкніть **Contains secret values**
   - `TELEGRAM_CHAT_ID` — значення: число chat_id
   Scopes — усі (або щонайменше **Functions**). Зберегти.
3. **Deploys** → **Trigger deploy** → **Deploy site** (щоб змінні підхопилися).
4. Залиште тестову заявку на сайті — вона має прийти в Telegram, а сайт показати «Дякуємо! Заявку прийнято».

Якщо заявка не приходить: Netlify → **Logs** → **Functions** → `lead` — там буде рядок «Заявку не доставлено: Telegram HTTP …» з кодом помилки (401 — неправильний токен, 400 — неправильний chat_id або бот не отримав /start).

## Як оновлювати сайт

Будь-яка зміна файлів на GitHub (кнопка ✏️ біля файлу або повторне завантаження) — і Netlify за хвилину сам оновить сайт.
Наприклад, змінити телефон: GitHub → `public/config.js` → ✏️ → виправити → **Commit changes**.

## Власний домен (пізніше)

Купіть домен (наприклад, `kiviservice.com.ua`) → Netlify → проєкт → **Domain management** → **Add a domain** → дотримуйтесь підказок. HTTPS Netlify налаштує сам. Після цього варто додати `sitemap.xml` і картинку для прев’ю в соцмережах — це зробимо разом.

## Перевірка після публікації

- [ ] Сайт відкривається з телефона, кнопка «Подзвонити» набирає 068 018 80 85
- [ ] «Написати в Telegram» відкриває чат (перевірити з іншого телефона)
- [ ] Посилання Instagram, TikTok, Facebook відкриваються
- [ ] Посилання «Політика конфіденційності» під формою працює
- [ ] Без бота форма показує «Заявку не надіслано…» (а не помилку зв’язку) — значить функція працює
- [ ] Після кроку 3 — тестова заявка приходить у Telegram
